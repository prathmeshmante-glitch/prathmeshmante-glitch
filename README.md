## 05 / HOW TO INTERACT WITH V.E.R.A.

1. Open the **V.E.R.A. Command Deck** using the badge at the top.
2. Allow microphone access and speak the demo passphrase when prompted.
3. Once authorized, activate the voice channel and ask for a project or README briefing.
4. Choose **Ask V.E.R.A.** on a repository card to hear its public metadata and README summary.

**Current engineering limits:** browser speech recognition and the available feminine-sounding voice depend on the visitor's device and browser. The guide reads public GitHub metadata and README content; it is not yet connected to a generative AI model. The passphrase is a demonstration gate, not real security. A public webpage cannot identify the visitor's GitHub account without a sign-in flow, and saying a name is not identity verification.
